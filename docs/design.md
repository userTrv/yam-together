# Дизайн

**Когда пригодится:** перед любой правкой интерфейса, чтобы не размыть направление.

Сделано по двум скиллам: [unslop](https://github.com/heydamir/unslop) Дамира Соколовского (CC BY 4.0) для приложения и визуальной системы, [landing-page-design](https://github.com/elayadesign/ai-design-skills) для структуры и текстов лендинга. Где они спорят, решение записано ниже.

## Направление

- **Продукт.** Общая комната, где у всех в наушниках один трек в одну секунду, каждый со своего телефона.
- **Характер.** Ночной, точный, компанейский.
- **Мир.** Московское метро поздно вечером: схема линий, станционные табло, натриевый свет тоннеля.
- **Моменты.** Очередь нарисована как ветка метро: каждый трек — станция, участок линии окрашен цветом того, кто добавил трек. Обложки демо-треков — маленькие схемы линий, у каждого трека своя.
- **Подпись.** Станция-кольцо, как пересадка на схеме. Ею отмечены треки в очереди, пассажиры, автор трека и логотип.

## Система

| Слой | Решение |
| --- | --- |
| Поверхности | Чернильный ряд unslop: `#0b0d14` фон, `#11141c` карточки, `#1a1e28` приподнятые. Волосяные линии 8% |
| Текст | Три роли: `#eef0f5`, `#a3a9b8`, `#7a8296` |
| Акцент | Натриевая лампа `#ffb547`, только тёмный текст на нём. Главная кнопка, текущая станция, ссылки |
| Цвет данных | Палитра линий метро для пассажиров. Это единственное место, где много оттенков, и каждый что-то значит |
| Шрифт | Manrope 400/500/600 для интерфейса, JetBrains Mono для кода вагона, времени и миллисекунд. Оба с кириллицей |
| Иконки | Lucide, 18 px, обводка 1,5, цвет текстовой роли |
| Радиусы | 6 / 10 / 16 / 20, вложенные считаются как внешний минус отступ |
| Движение | Одна кривая `cubic-bezier(0.22, 1, 0.36, 1)`, 160 / 220 / 420 мс, только `transform`, `opacity`, цвета. Всё отключается при `prefers-reduced-motion` |

## Где скиллы расходятся и что выбрано

- **Шрифт.** landing-page-design запрещает Inter и предлагает Geist/Manrope, unslop разрешает выбирать по характеру. Взят Manrope: он из разрешённых, с хорошей кириллицей и чуть теплее Geist.
- **Градиент на заголовке героя.** landing-page-design требует градиент белый→серый, unslop называет градиентный текст признаком слопа. Оставлен сплошной цвет: заголовок короткий и крупный, ему не нужна помощь.
- **Иконки.** landing-page-design советует Phosphor, unslop — набор проекта или lucide. Взят lucide: иконки вписаны прямо в разметку, без зависимости.
- **Реакции эмодзи.** unslop убирает эмодзи из интерфейса. Здесь они не украшение, а контент, который пассажиры отправляют друг другу, поэтому остались только в панели реакций и в летящих реакциях.

## Аудит по unslop

Чего нет и не должно появиться: фиолетовых градиентов, свечений, стеклянных карточек, бейджей «New», капса с трекингом, пульсирующих элементов, `transition: all`.

Что проверено на скриншотах 390 px и 1440 px:

- нет горизонтальной прокрутки;
- на телефоне кнопка «играть» и статус синхронизации видны на первом экране, обложка ограничена `36dvh`;
- все интерактивные элементы имеют hover, active и фокус;
- пустые состояния: «Пока тихо» с пустой станцией, линия с пунктирной станцией и подсказкой;
- ошибки пишут, что случилось и что делать: «Нет связи, команда не ушла. Попробуйте на станции».

## Лендинг

Тип A по landing-page-design: классический герой и секции, продукт понятен по скриншоту. Порядок: герой (текст слева, телефон с живым вагоном справа) → слоган с проявлением слов → как это работает (три станции на одной линии) → сделан для метро (схема перегона без сети) → где пригодится → своя Яндекс Музыка у каждого → вопросы → финальный призыв. Одна главная кнопка «Создать вагон», вторичное действие — поле для кода.

Непроверяемых цифр нет. «До 60 мс» — консервативная оценка для разных телефонов, в e2e-тесте на одной машине разброс 3–4 мс.
